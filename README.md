# The Ivory House – Hotel Website

A multi-page website for **The Ivory House**, a fictional luxury hotel in Belfast. Built with HTML, CSS, JavaScript and jQuery.

**🔗 Live site:** https://fm10kelly-collab.github.io/ivory-house-hotel-website/

Group project for **COM109 at Ulster University (Group 23)**.

## Pages

| Page | What it includes |
|---|---|
| **Home** | Hero banner, featured rooms and "Curated Stays" tabs |
| **Rooms** | Room cards with prices and a clickable comparison table |
| **Facilities** | "Learn More" cards that slide open, plus an FAQ accordion |
| **Gallery** | Category filter, lightbox image viewer and keyboard navigation |
| **Contact** | Enquiry and booking form with live validation, plus an FAQ accordion |

## Built with

- **HTML5**, with a skip link and ARIA labels for accessibility
- **CSS3**: a shared stylesheet plus one stylesheet per page, responsive layout
- **JavaScript / jQuery 3.7**: all page interactivity
- **GitHub Pages** for hosting

## Folder structure

```
CSS/      stylesheets (style.css is shared by every page)
Images/   photos, logo and favicon
Js/       one script per page, plus script.js for shared features
*.html    the five pages
```

## Run it locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## What I learned

- Splitting a website into reusable shared CSS and page-specific files
- Using jQuery for interactive features such as validation, accordions and a lightbox
- Working in a team with Git and GitHub
- **File paths on GitHub Pages are case-sensitive.** `images/` and `Images/` are different folders online, even though they work the same on a Mac.
